# Muhammad Marulli — extracted portfolio page assets

Source: `Portofolio_MUHAMMAD_MARULLI(2).pdf` (9 pages).

IMPORTANT:
- The PDF stores each page as one flattened raster image.
- These exports preserve complete page compositions/collages; they are NOT individually isolated artwork files.
- Some page exports are repeated across category folders because a page contains multiple kinds of work.
- For a polished project gallery, individual artwork panels should be cropped from the original design files or carefully separated in a second pass.
